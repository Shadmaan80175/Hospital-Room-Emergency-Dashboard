🏥 Hospital Emergency Room Dashboard (Excel)
📌 Project Overview

This project presents an interactive Excel dashboard designed to analyze and monitor Hospital Emergency Room (ER) performance.
The dashboard converts raw hospital data into meaningful insights to support operational efficiency, patient flow analysis, and data-driven decision-making.

🎯 Objectives

• Track overall ER performance on a monthly and yearly basis

• Analyze patient wait times and attendance status

• Understand admission trends and department referrals

• Study patient demographics (age groups and gender)

• Provide a clear, visually appealing dashboard for stakeholders

📊 Key Metrics & Insights

• Total Number of Patients

• Average Wait Time (Minutes)

• Patient Satisfaction Score

• On-Time vs Delayed Attendance

• Admission Status (Admitted vs Not Admitted)

• Patients by Gender

• Patients by Age Group

• Patients by Department Referral

🧩 Dashboard Features

📅 Year & Month slicers for dynamic filtering

📈 Interactive charts and KPIs

📊 Clean and professional dark-themed layout

🔄 Automatically updates with filtered selections

🛠 Tools & Techniques Used

• Microsoft Excel

• Pivot Tables & Pivot Charts

• Slicers & Timeline Filters

• Data Cleaning & Data Modeling

• Dashboard Design & Visualization Best Practices

📂 Files Included

🚀 How to Use

1. Download the Excel file from this repository

2. Open in Microsoft Excel (desktop version recommended)

3. Use the Year and Month slicers to explore insights dynamically
